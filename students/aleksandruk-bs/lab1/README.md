Метки переведены в \(\{\pm 1\}\), к признакам добавлен столбец единиц (свободный член).

Линейная модель уместна: после стандартизации классы хорошо режутся гиперплоскостью (эталон и скорейший спуск дают AUC около 0,99).

## Модель

Отступ: \(M_i=y_i\langle w,x_i\rangle\). Верно при \(M_i>0\).

Потеря: \(L(M)=(1-M)^2\). При \(y=\pm 1\) это та же среднеквадратичная ошибка \((y-\langle w,x\rangle)^2\).

\[
Q(w)=\frac{1}{\ell}\sum_{i=1}^{\ell}(1-M_i)^2+\frac{\lambda}{2}\|w_{1:}\|^2,\quad \lambda=10^{-3}.
\]

Свободный член не штрафуем. Градиент одного объекта: \(\nabla L=-2(1-M)yx\).

Старт весов — как на лекции:

- равномерно на \(\bigl(-\frac{1}{2n},\frac{1}{2n}\bigr)\);
- \(w_j=\langle y,f_j\rangle/\langle f_j,f_j\rangle\);
- мультистарт из нескольких случайных точек.

## Реализация

| Пункт | Где |
|---|---|
| анализ выборки | `dataset.py`, график баланса / размаха / корреляций в `train.py` |
| отступ | `margins()`, график «номер — отступ» |
| градиент | `loss_gradient()`, `full_gradient()` |
| рекуррентная оценка | \(\hat Q\leftarrow(1-\gamma)\hat Q+\gamma L(M_i)\) в SGD |
| SGD с инерцией | \(v\leftarrow\mu v+\eta g,\ w\leftarrow w-v\); сравнение \(\mu=0\) и \(\mu=0{,}9\) |
| L2 | `l2_gradient()`; график \(\|w\|\) и доли верных при разных \(\tau\) |
| скорейший спуск | полный градиент и шаг \(\eta=\|g\|^2/(g^\top Hg)\) |
| предъявление пограничных | \(p_i\propto 1/(|M_i|+0{,}15)\), выбросы \(M<-2\) почти не берём |
| эталон | `RidgeClassifier`, \(\alpha=\lambda n/2\); сравниваем метрики, \(\|w\|\) и скорость |

Свой алгоритм — в `linear_classifier.py`. sklearn: данные, разбиение, стандартизация, метрики, эталон.

## Отступы

После старта по формуле лекции средний отступ \(\approx 8,4\), ошибок на обучении 26. Квадрат штрафует и \(M\gg 1\), поэтому SGD сжимает отступы к 1. После обучения средний отступ \(\approx 0,75\), ошибок 14.

Случайный старт на узком отрезке даёт отступы около нуля.

## Обучение

Пункт 9.3: один старт по формуле лекции, два предъявления.

Предъявление пограничных объектов: \(p_i\propto 1/(|M_i|+0{,}15)\), выбросы \(M_i<-2\) почти не показываем. На тесте AUC чуть выше случайного порядка (0,994 против 0,988), доля верных чуть ниже (0,942 против 0,953). Средняя потеря на обучении выше (0,394 против 0,232): модель чаще смотрит на границу.

SGD с инерцией и без неё за первую эпоху сбрасывают огромный стартовый \(Q\). Без инерции итоговый \(Q\) чуть меньше (0,228 против 0,232), на тесте лучше **с инерцией** (0,953 против 0,942).

L2: при росте \(\tau\) норма весов падает (0,439 → 0,276). На тесте качество почти плоское, небольшой пик при \(\tau=10^{-2}\) (доля верных 0,947). Штраф жмёт связанные признаки.

Скорейший спуск за 1–2 шага выходит на минимум \(Q\approx 0,219\). Мультистарт лучше всех на тесте.
