# Линейная классификация
## Данные
Использован набор [Banknote Authentication](https://www.kaggle.com/datasets/mastershomya/banknote-authetication), содержащий 4 количественных признака, полученных из изображений банкнот:

- variance — дисперсия вейвлет-преобразования;
- skewness — асимметрия;
- curtosis — эксцесс;
- entropy — энтропия.

Пропусков нет.

Таргет class содержит два класса. После удаления точных дубликатов осталось 1348 объектов: 738 класса 0 и 610 класса 1. Сильного дисбаланса нет. Перед запуском для соответствия формулам из презентации значения были приведёны к виду -1 и 1.

Также все признаки перед началом обучения были стандартизированы. Параметры стандартизации вычислены только по обучающей выборке. Данные разделены со стратификацией на обучающую, проверочную и тестовую выборки в пропорции 60/20/20.

## Классификаторы

Реализованы три линейных классификатора:

- Momentum — стохастический градиентный спуск с инерцией и L2-регуляризацией.
- Speediest — скорейший градиентный спуск.
- Mixed — дополнительный вариант, объединяющий инерцию, вычисление шага и L2-регуляризацию.

Для каждого метода проверены корреляционная инициализация и случайная инициализация с пятью стартами. В качестве эталона использовался готовый RidgeClassifier из sklearn.
