# PCA
## Данные
Использован встроенный датасет Diabetes из sklearn.datasets, содержащий 442 объекта и 10 числовых признаков. Признаки предварительно уже были нормализованы и центрированы.

## Реализация
Метод главных компонент был реализован на основе сингулярного разложения матрицы признаков с использованием np.linalg.svd() из библиотеки NumPy. 

Эффективная размерность выборки определялась по  $E_m \leq \varepsilon$, где $\varepsilon = 0.05$. 

Для проверки корректности использовался np.testing.assert_allclose(), позволяющий сравнивать численные результаты с учётом допустимой погрешности. Так были проверены совпадение восстановленных данных с эталонной реализацией sklearn.PCA, ортонормированность главных компонент. 

Были построены два графика: собственные значения главных компонент и зависимость $E_m$ от числа сохранённых компонент.

## Результаты
| Показатель | Значение |
|---|---|
| Исходная размерность | 10 |
| Эффективная размерность | 8 |
| Относительная ошибка аппроксимации $E_m$ | 0.008688 |
