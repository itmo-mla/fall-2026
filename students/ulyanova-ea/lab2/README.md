# KNN
## Данные
Использован набор [Banknote Authentication](https://www.kaggle.com/datasets/mastershomya/banknote-authetication), содержащий 4 количественных признака, полученных из изображений банкнот:

- variance — дисперсия вейвлет-преобразования;
- skewness — асимметрия;
- curtosis — эксцесс;
- entropy — энтропия.

Пропусков нет. Дубликаты присутствовали, но были удалены.

Таргет class содержит два класса. Сильного дисбаланса нет. Перед запуском для соответствия формулам из презентации значения были приведёны к виду -1 и 1. Разделение осуществлялось в соотношении 80 к 20 (1078 и 270 объектов соответственно).

Признаки стандартизировались.

## Подбор параметра k для окна Парзена с гауссовым ядром
Параметр выбирался среди значений от 1 до 50 методом LOO. Эмпиричиский риск оказался минимален при k = 1, что отражено на графике img\k_selection.png.

## Отбор эталонов
Отбор производился жадной стратегией удаления не-эталонов. В результате осталось 24 объекта-эталона (менее 5% от изначальной выборки). Для визуализации было принято решение построить 6 графиков: по одному для каждой пары признаков, но с пониманием, что классификация выполняется в полном четырёхмерном пространстве.

## Сравнение на отложенной тестовой выборке

Для сравнения по условию лабораторной в коде был использован KNeighborsClassifier из scikit-learn с равными весами соседей. В сравнении с иными его варианциями назначения весов в данном случае не было смысла, так как при выбранном k = 1 голосует и так только один объект.

 Алгоритм | Ошибок | Accuracy | F1 |
| --- | ---: | ---: | ---: |
| Парзен, все объекты | 1 | 0.9963 | 0.9959 |
| Парзен, эталоны | 0 | 1.0000 | 1.0000 |
| 1NN, все объекты | 0 | 1.0000 | 1.0000 |
| 1NN, эталоны | 3 | 0.9889 | 0.9879 |
| sklearn KNN, uniform | 0 | 1.0000 | 1.0000 |

Отбор сократил число хранимых объектов примерно в 45 раз. На данном разбиении окно Парзена после отбора классифицировало тестовую выборку без ошибок, тогда как качество 1NN немного снизилось.
