# Метод опорных векторов SVM
## Данные
Для демонстрации и сравнения работы классификаторов был использован синтетический датасет make_moons. Было создано 300 объектов, содержащих два числовых признака. В датасете два сбалансированных класса в форме полумесяцев.

Параметры генерации: noise=0.15, random_state=42. Для дальнейшей работы метки были преобразованы в −1/+1. Разбиение: 70% для обучения, 30% для тестирования с сохранением соотношения классов. Признаки стандартизированы через StandardScaler, обученный только на обучающей выборке.

## Реализации
Собственный SVM реализован через решение двойственной задачи по множителям Лагранжа с помощью scipy.optimize.minimize (по умолчанию для задачи использовался SLSQP, при этом важно было учитывать, что при численной минимизации вместо точного нуля лямбда может получиться очень малым положительным числом, например, 0.0000000001. Поэтому сравнение с 0 заменено неравенством > 1e-6. Для выделения граничных опорных объектов также учитывался допуск). Передан аналитический градиент, заданы ограничения:

$$
0 \leq \lambda_i \leq C,\qquad \sum_i \lambda_i y_i=0.
$$

Выбраны три ядра:

$$
K_{\text{linear}}(x,x')=\langle x,x'\rangle;
$$

$$
K_{\text{poly}}(x,x')=(\langle x,x'\rangle+1)^3;
$$

$$
K_{\text{RBF}}(x,x')=\exp(-\gamma\|x-x'\|^2).
$$

Подбор гиперпараметров не производился.
