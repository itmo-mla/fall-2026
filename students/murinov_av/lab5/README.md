# Лабораторная работа №5: Логистическая регрессия

## 1. Цель работы
Реализовать алгоритм логистической регрессии с использованием метода Ньютона-Рафсона и итеративного перевзвешивания наименьших квадратов (IRLS), а также продемонстрировать его эквивалентность эталонной реализации из библиотеки `scikit-learn`.

## 2. Теоретическая справка
Логистическая регрессия является частным случаем Обобщённой линейной модели (GLM). 

Для бинарной классификации ($y_i \in \{0, 1\}$) целевая переменная моделируется распределением Бернулли:
$$ p(y_i | \mu_i) = \mu_i^{y_i} (1 - \mu_i)^{1 - y_i} $$

Естественный параметр экспоненциального семейства: $\theta_i = \ln \frac{\mu_i}{1 - \mu_i}$.  
Функция связи (link function): $\mu_i = \sigma(\theta_i) = \frac{1}{1 + \exp(-\theta_i)}$, где $\theta_i = x_i^T w$.

Минимизация логарифмической функции потерь (log-loss) с добавлением L2-регуляризации:
$$ Q(w) = \sum_{i=1}^{\ell} \left[ -y_i \ln(\mu_i) - (1 - y_i) \ln(1 - \mu_i) \right] + \frac{\lambda}{2} \|w\|^2 \to \min_w $$

Метод Ньютона-Рафсона для минимизации этого функционала приводит к алгоритму **IRLS** (Iteratively Reweighted Least Squares):
1. Градиент: $\nabla Q(w) = X^T (\mu - y) + \lambda w$
2. Гессиан: $H = X^T W X + \lambda I$, где $W = \text{diag}(\mu_i (1 - \mu_i))$
3. Шаг обновления: $w_{t+1} = w_t - H^{-1} \nabla Q(w_t)$

На каждой итерации задача сводится к взвешенной задаче линейной регрессии, где объекты, близкие к границе решающей поверхности (где $\mu_i \approx 0.5$), получают наибольший вес $W_{ii}$, что обеспечивает более точную настройку на «трудных» объектах.

## 3. Описание датасета
Использован датасет **Breast Cancer Wisconsin** (встроен в `sklearn.datasets`). 
- **Задача:** Бинарная классификация (доброкачественная / злокачественная опухоль).
- **Признаки:** 30 числовых признаков, предварительно стандартизированных (`StandardScaler`).
- **Разделение:** 80% обучение, 20% тестирование.

## 4. Реализация
- Разработан класс `LogisticRegressionIRLS`, реализующий обучение с помощью метода Ньютона-Рафсона (IRLS).
- Для численной стабильности добавлено ограничение значений сигмоиды (`np.clip`) и регуляризация гессиана ($\epsilon I$).
- В качестве эталона использована `sklearn.linear_model.LogisticRegression` с параметрами `solver='newton-cg'` и идентичным коэффициентом регуляризации `C`.
