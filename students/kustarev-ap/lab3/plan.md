## 2. Решение двойственной задачи по λ (пункт задания №2)

Теория (лекция, слайды 7–11): вместо прямой задачи ищем множители Лагранжа λ:

```
L(λ) = -Σλ_i + 1/2 ΣΣ λ_i λ_j y_i y_j K(x_i,x_j)  → min_λ
при  Σ λ_i y_i = 0,   0 ≤ λ_i ≤ C
```

**Вход**: обучающая подвыборка `(X_train_sub, y_train_sub)`, матрица Грама `K` (на этом шаге — линейное ядро `K(x,x')=⟨x,x'⟩` как базовый случай), гиперпараметр `C`.

**Метод** (`svm_dual.py`):
- строим `K = X @ X.T` (или через модуль ядер из п.3 — функция принимает любое ядро);
- целевая функция и **аналитический градиент** передаются в `scipy.optimize.minimize`:
  - `f(λ) = -Σλ + 0.5 * λᵗ (yyᵗ ∘ K) λ`
  - `∇f(λ) = (yyᵗ ∘ K) λ - 1`
- ограничение равенства `Σλ_i y_i = 0` — через `LinearConstraint` (или `{'type':'eq', 'fun': ...}`);
- ограничения `0 ≤ λ_i ≤ C` — через `bounds`;
- метод — `SLSQP` (поддерживает общие ограничения; альтернатива — `trust-constr`, сравнить сходимость/скорость на подвыборке);
- старт — λ₀ = 0 или малые случайные значения в допустимой области.

После сходимости:
- опорные векторы — объекты с `λ_i > ε` (например, `ε=1e-5`);
- порог `w0` — усреднение по опорным "граничным" векторам (`0 < λ_i < C`, т.е. `M_i=1`): `w0 = mean( K(x_i,·)·(λ·y) - y_i )` для таких i (устойчивее, чем взять один объект);
- классификатор: `a(x) = sign( Σ λ_i y_i K(x, x_i) - w0 )`.

**Выход**: вектор `λ*`, индексы опорных векторов, `w0`, флаг сходимости оптимизатора, значение двойственного функционала.

**Проверка качества этого шага (KKT)**:
- `0 ≤ λ_i ≤ C` для всех i (численно, с допуском);
- `|Σ λ_i y_i| < tol`;
- доля опорных векторов разумна (не 0%, не 100%);
- `optimizer.success == True`, иначе — пробовать другой метод/старт.

## 3. Трюк с ядром (пункт задания №3)

**Вход**: решатель двойственной задачи из п.2, параметризованный функцией ядра.

**Метод** (`kernels.py` + повторное использование `svm_dual.py` с разными `K`):
- `linear(X1, X2) = X1 @ X2.T`;
- `polynomial(X1, X2, degree, coef0=1) = (X1 @ X2.T + coef0) ** degree`;
- `rbf(X1, X2, gamma) = exp(-gamma * ||x_i - x_j||²)` (через `scipy.spatial.distance.cdist` с `sqeuclidean`, векторизовано);
- каждая функция возвращает матрицу Грама `N1×N2` (нужна и NxN для обучения, и N_test×N_sv для предсказания — одна и та же функция с разными аргументами).

Подбор гиперпараметров (аналог LOO/CV из lab2): k-fold cross-validation (например, 5 фолдов) на обучающей подвыборке по сетке:
- линейное: только `C`;
- полиномиальное: `C × degree (2,3) × coef0`;
- RBF: `C × gamma` (сетка вокруг `1/(n_features*Var(X))`, как эвристика sklearn `'scale'`).

Критерий выбора — средняя accuracy (и F1, т.к. классы почти сбалансированы, но проверим) по фолдам.

**Выход**: для каждого типа ядра — лучшие гиперпараметры, кривые CV-accuracy от `C`/`gamma`/`degree`, обученная модель (λ*, SV, w0) на полном train_sub с лучшими параметрами.

**Графики:**

- `02_cv_linear.png` — линейный график. Ось X — `C` (логарифмическая шкала), ось Y — значение метрики. Две линии одного цвета из палитры: accuracy — сплошная, F1 — пунктирная, с маркерами в каждой точке сетки. Вертикальная серая пунктирная линия отмечает выбранное оптимальное `C`, рядом подпись со значением. Заголовок: «CV: линейное ядро». Легенда — «accuracy», «F1», «выбранное C».
- `03_cv_poly.png` — линейный график, ось X — `C` (лог. шкала), ось Y — CV-accuracy (отдельно F1 — на второй панели рядом, либо той же палитрой пунктиром, если не загромождает). Каждому `degree` (2, 3) — свой цвет из `tab10`, `coef0` фиксируется в заголовке или выносится в подпись легенды построчно («degree=2, coef0=1»). Точка лучшей комбинации — выделена крупным маркером с чёрной обводкой. Заголовок: «CV: полиномиальное ядро».
- `04_cv_rbf.png` — heatmap CV-accuracy по сетке `C × gamma` (ось X — `gamma`, ось Y — `C`, обе в лог. шкале через подписи тиков). Последовательная палитра (`viridis`), colorbar с подписью «CV accuracy». Лучшая точка сетки — отмечена маркером «★» и аннотацией значения метрики. Заголовок: «CV: RBF-ядро».

## 4. Линейный классификатор (пункт задания №4)

**Вход**: решение двойственной задачи с линейным ядром (частный случай п.2–3).

**Метод** (`svm_dual.py`, функция `to_primal_weights`):
- явный переход к прямой задаче: `w = Σ λ_i y_i x_i`, `w0` — как в п.2;
- явная модель `a(x) = sign(⟨x,w⟩ - w0)`.

**Проверка**: предсказания через явное `w` и через `Σ λ_i y_i K(x,x_i)` (линейное ядро) должны совпадать с точностью до `1e-6` — sanity-check корректности перехода двойственная→прямая.

**Выход**: вектор весов `w` (4 числа) и `w0`; интерпретация — какой из 4 признаков (variance/skewness/curtosis/entropy) вносит наибольший вклад по `|w_j|` (после стандартизации веса сравнимы по шкале).
