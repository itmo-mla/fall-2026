## 2. Логистическая регрессия через метод Ньютона-Рафсона и IRLS (пункт задания №2)

Теория (лекция): модель `p_i = sigmoid(w^T x_i)`, функция правдоподобия Бернулли приводит к log-loss, метод Ньютона-Рафсона обновляет веса как `w_new = w - H^{-1} grad`, где `grad = X^T (y - p) - lambda*w`, `H = -(X^T W X + lambda*I)`, `W = diag(p_i (1 - p_i))`. IRLS формулирует тот же шаг как взвешенный МНК: `z = X w + W^{-1}(y - p)`, `w_new = (X^T W X + lambda*I)^{-1} X^T W z` — направление обновления у обоих методов совпадает (вопрос теории №8), это нужно явно показать, а не просто продекларировать.

**Вход**: `X_train, y_train` (стандартизованные), параметр регуляризации `lambda` (небольшой L2, нужен из-за почти линейной разделимости выборки — без него Хessиан вырождается, веса расходятся, что отдельно демонстрируется как побочный эффект, см. бонус ниже).

**Метод** (`logreg_irls.py`):
- `sigmoid(z)` — векторизованная логистическая функция;
- `newton_step(X, y, w, lam)` — считает `grad` и `H` по формулам выше, возвращает `w - solve(H, grad)` (через `np.linalg.solve`, не явное обращение матрицы);
- `irls_step(X, y, w, lam)` — считает `z` и решает взвешенную нормальную систему `(X^T W X + lam*I) w_new = X^T W z` тем же `np.linalg.solve`;
- **проверка эквивалентности направлений**: на одном и том же `w` (например, после 1-2 итераций) сравнить `newton_step(...)` и `irls_step(...)` — должны совпадать с точностью до `1e-10`. Это прямая иллюстрация вопроса теории №8, а не просто фраза в отчёте;
- основной цикл обучения `fit(X, y, lam, max_iter, tol)` использует один из двух шагов (они эквивалентны, перебирать оба как метод обучения избыточно) до сходимости по изменению log-loss;
- история log-loss по итерациям сохраняется для графика сходимости.

**Выход**: обученные веса `w` (31 число — 30 коэффициентов + свободный член), история log-loss по итерациям, график `03_convergence.png`.

**Графики:**

- `03_convergence.png` — линейный график: ось X — номер итерации, ось Y — log-loss на train (возможно, логарифмическая шкала, если спад очень быстрый). Заголовок: "Сходимость Ньютона-Рафсона / IRLS" — ожидается квадратичная сходимость метода Ньютона, то есть выход на плато за единицы итераций.

**Бонус (не обязательный пункт задания, но прямая иллюстрация вопроса теории №16)**: отдельный короткий прогон без регуляризации (`lam=0`) — показать, что норма весов `‖w‖` растёт от итерации к итерации почти без остановки (или Хessиан становится плохо обусловленным / вырожденным и метод падает с ошибкой/NaN), в отличие от регуляризованной версии, где норма стабилизируется. Оформляется графиком `04_weight_norm_regularized_vs_not.png` (ось X — итерация, ось Y — норма `w`, две линии: `lam=0` и `lam` из основной модели) с короткой подписью, без отдельного раздела с формулами.

## 3. Эквивалентность с эталонной реализацией (пункт задания №3)

**Вход**: тот же `X_train`/`X_test`, обученная своя модель с `lam`, `sklearn.linear_model.LogisticRegression(penalty="l2", C=1/lam, solver="lbfgs")` — тот же тип регуляризации и та же её сила, иначе сравнение нечестное (эталон, разрешено правилом 7).

**Метод** (`compare_sklearn.py`):
- обучить `sklearn.linear_model.LogisticRegression` с `C = 1/lam` на тех же данных;
- задача строго выпуклая (log-loss + L2-штраф, Hessian положительно определён при `lam > 0`) — у неё единственный глобальный минимум, поэтому обе реализации должны сойтись к практически одному и тому же `w`, если обе корректны;
- сравнить коэффициенты (`max|w_mine - w_sklearn|`), предсказанные вероятности на test (`max|p_mine - p_sklearn|`), accuracy/log-loss на test, confusion matrix.

**Выход**: таблица/короткий текст с числами расхождений, графики `05_decision_boundary.png`, `06_confusion_matrices.png`, `07_compare_coefficients.png`.

**Графики:**

- `05_decision_boundary.png` — проекция train на 2 главные компоненты (`PCA(n_components=2)`), поверх — отдельная модель (своя реализация), обученная прямо в 2D-пространстве PCA для иллюстрации (явно отмечается в README как иллюстративная, а не та модель, по которой считаются метрики — так же, как в lab3). Решающая граница своей реализации — сплошная чёрная линия, граница sklearn, обученного на тех же 2D-данных — пунктирная серая линия поверх того же графика. Если реализации эквивалентны, линии почти совпадают. Точки — по классовой цветовой схеме. Заголовок: "Решающая граница: своя реализация vs sklearn (PCA-проекция)".
- `06_confusion_matrices.png` — две панели (`1×2 subplot`), confusion matrix на test отдельно для своей реализации и для sklearn (полноразмерная модель на 30 признаках, не иллюстративная 2D). Heatmap, палитра `Blues`, в ячейках — число объектов и доля. Заголовок каждой панели — модель + accuracy.
- `07_compare_coefficients.png` — горизontal bar chart: топ-10 признаков по `|w|` (своя реализация), два столбца на признак (своя реализация / sklearn) для прямого сравнения величины и знака коэффициента. Заголовок: "Коэффициенты логистической регрессии: своя реализация vs sklearn (топ-10 по модулю)".
