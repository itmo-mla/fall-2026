# Лабораторная работа №2. Метрические методы классификации

Метод k ближайших соседей с окном Парзена переменной ширины, подбор k скользящим контролем (LOO) и жадный отбор эталонов по критерию полного скользящего контроля CCV.

## Набор данных

Dry Bean Dataset (Kaggle) - определение сорта сухой фасоли по геометрическим признакам зерна, измеренным на фотографии.

### Предобработка и масштабирование

Классификатор решает, к какому классу отнести объект, по его ближайшим соседям, а близость измеряется евклидовым расстоянием:

ρ(x, x′) = √(Σⱼ (xⱼ − x′ⱼ)²)

Расстояние складывает квадраты разностей по всем признакам. Без нормировки разница в площадях в тысячи пикселей полностью заглушила бы разницу в эксцентриситете в десятые доли. Фактически соседи искались бы по одной площади, а признаки формы не влияли бы вообще. Поэтому каждый признак мы приводим к нулевому среднему и единичному разбросу:

xⱼ ← (xⱼ − μⱼ) / σⱼ

μⱼ и σⱼ считаются только по обучающей выборке и затем применяются и к обучению, и к тесту. Если считать их по всем данным, информация о тесте просочится в подготовку, произойдет утечка. Если у какого-то признака σ = 0, программа останавливается с ошибкой, а не делит на ноль.

Порядок действий: сначала разбиваем данные, затем считаем параметры стандартизации по обучающей части.

## Реализация

Всё, кроме эталона для сравнения, реализовано самостоятельно на NumPy: разбиение, стандартизация, метрики (accuracy, balanced accuracy, матрица ошибок), PCA для визуализации, сам классификатор, LOO, критерий CCV и отбор эталонов. Из scikit-learn используется только `KNeighborsClassifier` как эталонная реализация в п. 4.

**KNN с окном Парзена переменной ширины (п. 1).** Для объекта x сортируем обучающую выборку по расстоянию до него: x⁽¹⁾ - ближайший сосед, x⁽²⁾ - следующий и так далее. Решение принимается взвешенным голосованием k ближайших соседей:

a(x) = argmax_y Σᵢ₌₁ᵏ [y⁽ⁱ⁾ = y] · K(ρ(x, x⁽ⁱ⁾) / h(x))

Здесь [·] равно 1, если условие верно, и 0 иначе. Каждый сосед голосует за свой класс с весом K(ρ/h), и побеждает класс с наибольшим суммарным весом.

Ширина окна своя у каждого объекта: h(x) = ρ(x, x⁽ᵏ⁺¹⁾), расстояние до (k+1)-го соседа. В плотной области соседи близко, и окно узкое. В разреженной - далеко, и окно широкое. Поэтому у любого объекта голосуют ровно k соседей, а при фиксированной ширине окна в разреженной области соседей могло бы не оказаться вовсе.

Ядро гауссово: K(r) = exp(−2r²). Оно убывает с расстоянием, поэтому ближние соседи весят больше дальних. Если h = 0 (k+1 соседей совпадают с x), берём r = 0: все голоса с весом K(0) = 1.

**Скользящий контроль LOO (п. 2).** Чтобы выбрать k, нужно оценить качество классификатора без теста. Каждый обучающий объект по очереди убирается из выборки и классифицируется по оставшимся:

LOO(k) = (1/ℓ) · Σᵢ₌₁ˡ [a(xᵢ; Xˡ \ {xᵢ}, k) ≠ yᵢ]

Объект исключается по индексу (`np.delete`), поэтому он не может проголосовать сам за себя. LOO считается для k = 1…20, выбирается k с наименьшим эмпирическим риском.

**Эталон (п. 4).** `KNeighborsClassifier(n_neighbors=k, metric="euclidean", weights="distance")` с тем же k. Это не то же самое, что наш алгоритм: вместо окна Парзена соседи взвешиваются как 1/ρ. Так мы сравниваем наш метод со стандартной реализацией взвешенного KNN.

**Критерий полного скользящего контроля CCV (п. 5).** Отбор эталонов - это поиск подмножества Ω обучающей выборки, по которому классификатор работает не хуже, чем по всей выборке. Критерий качества такого подмножества - CCV(Ω) из лекции. Для каждого объекта xᵢ смотрим его ближайших соседей среди эталонов и отмечаем, чужого ли они класса:

eⱼ(xᵢ) = [yᵢ ≠ yᵢ⁽ʲ⁾], где xᵢ⁽ʲ⁾ - j-й сосед xᵢ среди Ω \ {xᵢ}

T(xᵢ, Ω) = Σⱼ₌₁ᴷ eⱼ(xᵢ) · Γ(j)

CCV(Ω) = (1/L) · Σᵢ₌₁ᴸ T(xᵢ, Ω)

Оцениваются все L объектов обучающей выборки, в том числе не вошедшие в Ω: эталоны должны правильно классифицировать всю выборку, а не только себя.

Вес Γ(j) - вероятность того, что при случайном разбиении выборки на обучение длины ℓ′ и контроль ближайшим обучающим соседом контрольного объекта окажется именно его j-й сосед:

Γ(j) = C(L−1−j, ℓ′−1) / C(L−1, ℓ′)


**Жадное удаление не-эталонов (п. 5).** Алгоритм со слайда лекции:

```
Ω := Xᴸ
повторять
    найти x ∈ Ω: CCV(Ω \ {x}) → min
    Ω := Ω \ {x}; обновить T(xᵢ, Ω) для всех xᵢ: x ∈ kNN(xᵢ)
пока CCV уменьшается или почти не увеличивается
```

Если на каждом шаге пересчитывать CCV заново для каждого из ~10 000 кандидатов, одна итерация заняла бы десятки часов. Поэтому мы пользуемся тем, что удаление эталона меняет T только у объектов, для которых он был одним из ближайших эталонов. Для каждого xᵢ хранятся его K+1 ближайших эталонов. Удаление эталона, стоящего на месте p, сдвигает более дальних соседей на одно место ближе:

dTᵢ(p) = Σ_{q=p}^{K−1} (e_{q+1} − e_q) · Γ(q)

Сумма dTᵢ по всем объектам, у которых кандидат x среди ближайших эталонов, даёт изменение критерия L·(CCV(Ω \ {x}) − CCV(Ω)) сразу для всех кандидатов. Поэтому на каждом шаге перебираются все кандидаты и выбирается минимум - алгоритм остаётся жадным. После удаления пересчитываются только объекты, у которых удалённый был среди K+1 ближайших эталонов. Это и есть «обновить T(xᵢ, Ω) для всех xᵢ: x ∈ kNN(xᵢ)» со слайда.

Остальные правила:
- **Допуск.** «Почти не увеличивается» реализовано так: удаление продолжается, пока CCV не превышает достигнутый минимум больше чем на 0.01.
- **Последний эталон класса** не удаляется, иначе этот класс нельзя было бы предсказать.
- **Проверка.** В конце программа пересчитывает CCV итогового набора прямо по определению и сравнивает с быстрым пересчётом. При расхождении работа останавливается с ошибкой.

**k для эталонов (п. 7).** Лучшее k подобрано для всей выборки, а эталоны - другая, гораздо меньшая опорная выборка. Поэтому k для неё подбирается заново: по доле ошибок на удалённых объектах обучения, k = 1…20. Тест в этом не участвует.

Общие параметры: k = 1…20 для LOO, доля теста 0.2, seed 42, ядро K(r) = exp(−2r²), ℓ′/L = 0.5, отбрасываемый хвост весов 10⁻⁴, допуск CCV 0.01.

**Почему риск при k = 1 и k = 2 одинаковый.** Это следствие устройства метода, а не ошибка. При k = 2 голосуют два соседа, и ядро убывает, поэтому ближайший сосед всегда весит не меньше второго. Если соседи разных классов, побеждает ближайший. Значит, при k = 2 ответ всегда совпадает с ответом одного ближайшего соседа.

**Форма кривой.**
- **k от 1 до 8.** Риск быстро падает с 0.0978 до 0.0793. Когда решает один-два соседа, одного шумового объекта рядом (зерна чужого сорта внутри нашего облака) достаточно для ошибки. С ростом k влияние отдельного соседа уменьшается.
- **k от 8 до 20.** Кривая выходит на плато: риск колеблется между 0.0776 и 0.0796. Разница между минимумом при k = 12 и значением при k = 20 - 0.0017, около 18 объектов из 10 890. Стандартная ошибка оценки риска √(0.0776·0.9224 / 10 890) ≈ 0.0026, то есть значения на плато статистически неразличимы.

**Обоснование выбора k.** k = 12 - минимум эмпирического риска. Широкое плато показывает, что выбор устойчив: любое k от 8 до 20 дало бы практически то же качество, и точное значение не принципиально.

### Отбор эталонов

Начальное состояние: |Ω| = 10 890, CCV(Ω) = 0.1029, глубина профиля K = 14, Γ(1) = 0.5.

CCV(Ω) = 0.1029 - ожидаемая доля ошибок метода ближайшего соседа, если обучать его на случайной половине выборки и проверять на другой половине, в среднем по всем таким разбиениям. Это чуть больше LOO при k = 1 (0.0978), и так и должно быть: при LOO классификатор опирается почти на всю выборку, а здесь только на половину.

1. **Удаление шума, 10 890 → ~7 900.** CCV падает с 0.1029 до 0.0534. Удаляются объекты, окружённые зёрнами чужого сорта. Такой объект сбивает классификацию своих соседей, и его удаление исправляет их ошибки. Набор без шума классифицирует выборку лучше, чем вся выборка.

Отбор остановился по правилу «почти не увеличивается»: следующее удаление подняло бы CCV выше минимума 0.0533 больше чем на допуск 0.01. В выводе программы: «CCV вырос больше допустимого (0.0633 > 0.0533 + 0.01)». Оба числа округлены до четырёх знаков, реально кандидат превышает порог в следующем знаке.

## Практические выводы

1. **Масштабирование признаков обязательно для метрических методов.** Признаки Dry Bean различаются по масштабу на семь порядков. Без стандартизации расстояние определялось бы одной площадью.

2. **Точное значение k не принципиально, важна область.** Слишком малое k делает классификатор чувствительным к отдельным шумовым соседям. На этих данных всё, что больше 8, даёт одинаковое качество в пределах погрешности.

3. **Ошибки определяются данными, а не реализацией.** Наш KNN и эталон sklearn ошибаются на одних и тех же объектах и путают одни и те же пары сортов (DERMASON ↔ SIRA, BARBUNYA ↔ CALI). Это пары, чьи облака перекрываются в пространстве признаков.

4. **Большая часть выборки для классификации не нужна.** Жадный отбор по CCV сначала удаляет шум (критерий улучшается), затем избыточные внутренние объекты (критерий не меняется). Остаются 5.78% объектов, лежащих вдоль границ классов.

5. **Параметры надо подбирать под опорную выборку.** Для всей выборки лучшее k = 12, для эталонов - k = 1. Если применить к эталонам k = 12, окно захватывало бы эталоны соседних классов.

6. **Подбор и оценку нельзя делать на одних и тех же данных.** k для эталонов выбран по удалённым объектам, и ошибка на них (0.0418) оптимистична, потому что эталоны отбирались под эти объекты. Честная оценка качества - только на тесте, который ни в каком выборе не участвовал.
