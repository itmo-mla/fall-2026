## Цель работы

Реализовать линейный классификатор с квадратичным loss, L2-регуляризацией и SGD с инерцией. Проверить способы инициализации и предъявления объектов, реализовать скорейший спуск и сравнить результат с эталоном.

## Датасет и постановка задачи

Использован [Used Car Dealer Dataset](https://www.kaggle.com/datasets/tungstor1/1b-parquet), содержащий 2000 записей об автомобилях.

Признак `sold` не использовался как таргет, поскольку он полностью определяется `Sales_ID`. Это создало бы утечку данных. Вместо него модель определяет тип топлива:

- `Diesel` соответствует классу `+1`
- `Petrol` соответствует классу `-1`

Редкие классы `CNG` и `LPG` исключены. После этого осталось 1980 объектов (1084 дизельных и 896 бензиновых автомобилей).

Используемые признаки:

| Признак | Смысл |
|---|---|
| `year` | год выпуска |
| `selling_price` | цена продажи |
| `km_driven` | пробег |
| `mileage` | расход или эффективность топлива |
| `engine` | объём двигателя |
| `max_power` | максимальная мощность |
| `torque_nm` | крутящий момент в Н·м |
| `torque_rpm` | обороты начала максимального момента |
| `seats` | количество мест |

`name` не используется, поскольку содержит большое количество конкретных моделей автомобилей. One-hot кодирование сильно увеличило бы число признаков и могло привести к запоминанию отдельных комплектаций вместо общих закономерностей.

### Обработка крутящего момента

Из строкового `torque` извлекаются момент и нижняя граница оборотов после `@` или `at`. `Nm` сохраняется, `kgm` переводится по правилу `1 kgm = 9.80665 Н·м`. Ошибочные подписи `kgm` у значений `115`, `130` и `145` обработаны как Н·м. Все значения преобразованы в `torque_nm`.

`torque_rpm` извлечён для 1968 из 1980 автомобилей. Оставшиеся 12 значений заполнены медианой похожих машин. Затем признаки стандартизированы, чтобы их масштабы одинаково влияли на градиент. `pyarrow` используется только для чтения Parquet через pandas и не участвует в классификации.

## Линейный классификатор

Основные обозначения:

- `x` — числовые признаки автомобиля;
- `y` — правильный класс: `+1` для Diesel и `-1` для Petrol;
- `w` — веса признаков, которые подбирает модель;
- `b` — свободный коэффициент;
- `f(x)` — числовой ответ модели;
- `M` — отступ объекта;
- `η` — шаг обучения;
- `λ` — коэффициент L2-регуляризации.

### Решающее правило и его геометрический смысл

Модель вычисляет взвешенную сумму признаков:

\[
f(x) = w^Tx + b
\]

Знак ответа задаёт класс, а `f(x) = 0` задаёт разделяющую плоскость. Вектор `w` определяет её направление, `b` отвечает за сдвиг. Удалённость от границы пропорциональна `|f(x)| / ||w||`.

### Отступ

Чтобы одновременно учитывать ответ модели и правильный класс, используется margin, или отступ:

\[
M_i = y_i f(x_i)
\]

Смысл знака отступа:

- `M < 0` — модель ошиблась;
- `M ≈ 0` — объект находится около разделяющей границы;
- `M > 0` — класс определён правильно.

Большой отрицательный отступ означает уверенную ошибку и может быть следствием шума или выброса. Шумом считаются случайные ошибки в данных, выбросом называется необычный объект. 

### Loss, эмпирический риск и функционал качества

Для одного объекта используется квадратичная loss-функция:

\[
L_i = (1 - M_i)^2
\]

Loss показывает величину ошибки и равен нулю при `M = 1`. Эмпирический риск является средним loss по train. Функционал качества добавляет к риску L2-штраф за большие веса.

Accuracy меняется скачками и не показывает направление изменения весов. Квадратичный loss плавный, поэтому для него можно вычислить градиент.

### Градиент и антиградиент

Градиент состоит из производных по всем весам и показывает направление самого быстрого увеличения функционала. Для одного объекта он вычисляется так:

\[
\nabla L_i = -2(1-M_i)y_i x_i + \lambda w
\]

Веса изменяются по антиградиенту, то есть против направления роста ошибки. `object_gradient` работает с одним автомобилем для SGD, `full_gradient` использует весь train для скорейшего спуска. L2 добавляет `λw`, но не штрафует свободный коэффициент `b`.

### Мультиколлинеарность

Мультиколлинеарность означает сильную линейную связь признаков. Корреляция `max_power` и `torque_nm` равна примерно `0.833`. Из-за этого отдельные веса хуже интерпретируются, хотя качество может оставаться высоким. Стандартизация не удаляет связь, а L2 снижает её последствия.

## Обучение

Общие параметры эксперимента: 80 эпох, momentum `0.9`, L2-коэффициент `0.01` и коэффициент рекуррентной оценки `0.02`. Для мультистарта выполняется пять запусков. Шаг SGD выбирается по валидационной выборке.

### Стохастический градиентный спуск с инерцией

На каждом шаге SGD выбирает один объект, вычисляет его градиент и обновляет веса. Momentum добавляет к текущему градиенту направление предыдущих шагов:

\[
\begin{aligned}
v_t &= \mu v_{t-1} + \nabla L_i
\\
w_t &= w_{t-1} - \eta v_t
\end{aligned}
\]

`v` хранит накопленное направление, `μ` задаёт инерцию, `η` задаёт шаг. Momentum сглаживает колебания SGD.

Чтобы следить за обучением без полного пересчёта функционала после каждого объекта, используется рекуррентная оценка:

\[
Q_t = (1-\alpha)Q_{t-1} + \alpha L_i
\]

`Q` является экспоненциальным скользящим средним ошибок. Параметр `α` задаёт влияние последнего объекта.

### Инициализация через корреляцию

Начальный вес каждого признака оценивается по его связи с правильным классом:

\[
w_j = \frac{\langle x_j,y\rangle}{\langle x_j,x_j\rangle}
\]

Знак веса показывает связь с классом. Такая начальная точка осмысленнее случайной, но не обязана быть оптимальной.

### Мультистарт

Модель обучается пять раз с разными случайными весами. Сохраняется запуск с минимальным функционалом на train.

### Предъявление по модулю отступа

Перед эпохой объекты сортируются по `|M|`. Сначала обрабатываются автомобили около границы, в которых модель уверена меньше всего.

### Скорейший градиентный спуск

В скорейшем спуске используется полный градиент по всей обучающей выборке. Направление задаётся антиградиентом, а длина шага автоматически рассчитывается для текущего квадратичного функционала:

\[
\eta_t = \frac{g_t^Tg_t}{g_t^THg_t}
\]

`g` является полным градиентом, `H` описывает кривизну функционала. Метод движется по `-g` и на каждом шаге использует весь train. Один шаг дороже SGD, но направление точнее.
