# Лабораторная работа №1. Линейная классификация

## Датасет

Используется Iris (`sklearn.datasets.load_iris`): 150 цветков ириса, 4 числовых признака (`sepal_length`, `sepal_width`, `petal_length`, `petal_width`) и 3 класса по 50 объектов.

Линейный классификатор решает задачу бинарной классификации, поэтому взяты два класса: **versicolor** ($y = -1$) и **virginica** ($y = +1$). Setosa отделяется от остальных классов плоскостью без ошибок, а versicolor и virginica частично пересекаются, поэтому на отступах есть что анализировать.

Предобработка:
- стандартизация признаков: $x := (x - \mu) / \sigma$;
- добавление константного признака $x_0 = 1$ (свободный член).

## Отступ объекта

Классификатор $a(x) = \mathrm{sign}\langle w, x \rangle$. Отступ объекта:

$$M_i = y_i \langle w, x_i \rangle$$

Если $M_i > 0$, объект классифицирован верно, если $M_i < 0$ — с ошибкой. Чем больше $|M_i|$, тем дальше объект от разделяющей гиперплоскости.

### Отступы при случайных весах

Веса выбраны случайно: $w_j \sim U\left(-\frac{1}{2n}, \frac{1}{2n}\right)$, $n = 5$.

![Отступы при случайных весах](images/margins_random.png)

Отступы маленькие (от −0.44 до 0.18), потому что маленькие сами веса. Ошибок 87 из 100: веса у `petal_length` и `petal_width` получились отрицательными, а у virginica эти признаки большие. Такая модель чаще ошибается, чем угадывает.
