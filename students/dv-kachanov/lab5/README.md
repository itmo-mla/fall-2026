## Логистическая регрессия

Вероятностная модель из лекции:

```text
p(x, w) = sigma(<x, w>) = 1 / (1 + exp(-<x, w>)).
```

Решающая функция:

```text
a(x, w) = [p(x, w) >= 0.5].
```

В коде сигмоида реализована в устойчивой форме без переполнения:

```python
def sigmoid(z):
    result = np.empty_like(np.asarray(z, dtype=float))
    positive = z >= 0
    result[positive] = 1.0 / (1.0 + np.exp(-z[positive]))
    exp_z = np.exp(z[~positive])
    result[~positive] = exp_z / (1.0 + exp_z)
    return result
```

## Функционал и L2-регуляризация

Минимизируется отрицательное логарифмическое правдоподобие с L2-регуляризацией:

```text
J(w) = -sum_{i=1}^{ell} (y_i ln p_i + (1 - y_i) ln(1 - p_i)) + (tau / 2) sum_{j=1}^{n} w_j^2.
```

Параметр:

```text
tau = 1.0.
```

Регуляризация необходима: классы в датасете почти линейно разделимы, и без нее веса уходят в бесконечность, а гессиан вырождается. Свободный член `w_0` не регуляризуется, как и в первой лабораторной работе. Значение `tau = 1.0` соответствует параметру `C = 1.0` эталонной модели.

В коде:

```python
def objective(X, y, w, l2=1.0):
    return -log_likelihood(X, y, w) + 0.5 * l2 * np.sum(w[1:] ** 2)
```

## Вычисление градиента

Градиент функционала считается через минимальную реализацию автоматического дифференцирования из первой лабораторной работы. Ее копия лежит в `source/autograd.py` и дополнена операциями `exp` и `log`, которых не было в исходной версии.

Отрицательное логарифмическое правдоподобие записывается без сигмоиды, через `softplus`:

```text
-LL(w) = sum_{i=1}^{ell} (softplus(z_i) - y_i z_i),
z_i = <x_i, w>,
softplus(z) = ln(1 + exp(z)).
```

Такая запись использует только операции, поддержанные автоградом. Свободный член исключается из регуляризации маской `(0, 1, ..., 1)`:

```python
scores = X_tensor @ w_tensor
softplus = (Tensor(1.0) + scores.exp()).log()
nll = (softplus + (-(y_tensor * scores))).mean() * float(len(X))
reg = (w_tensor * mask * w_tensor).mean() * (0.5 * l2 * float(n_features))
loss = nll + reg
```

Градиент получается вызовом:

```python
loss.backward()
```

После этого `w_tensor.grad` содержит `grad J(w)`.

Проверка градиента:

```text
Отклонение автоград-градиента от замкнутой формулы: 0.0.
```

Замкнутая формула `grad J(w) = X^T (p - y) + tau w` оставлена в коде (`gradient`) только для этой проверки; вся оптимизация идет на автоград-градиенте. Гессиан `H(w) = X^T R X + tau I` задан замкнутой формулой из лекции, так как минимальный автоград первой лабы считает только первые производные.

## Метод Ньютона-Рафсона

Градиент и гессиан функционала:

```text
grad J(w) = X^T (p - y) + tau w;
H(w) = X^T R X + tau I,  R = diag(p_i (1 - p_i)).
```

Итерация Ньютона-Рафсона:

```text
w^{t+1} := w^t - H(w^t)^{-1} grad J(w^t).
```

В коде линейная система решается без явного обращения матрицы:

```python
step = np.linalg.solve(hessian(X, w, l2), gradient(X, y, w, l2))
w = w - step
```

## Метод IRLS

В лекции показано, что квадратичная аппроксимация логарифмического правдоподобия сводит шаг Ньютона к взвешенному методу наименьших квадратов. Рабочий ответ:

```text
z = Xw + R^{-1} (y - p).
```

Итерация `IRLS`:

```text
w^{t+1} := (X^T R X + tau I)^{-1} X^T R z.
```

В коде:

```python
w = np.linalg.solve((X.T * weights) @ X + np.diag(penalty), (X.T * weights) @ z)
```

Подстановка `X^T R z = X^T R X w + X^T (y - p)` показывает, что это тот же шаг Ньютона, записанный в форме взвешенной регрессии. Поэтому оба метода обязаны давать одинаковые итерации с точностью до ошибок округления.

## Эквивалентность Ньютона-Рафсона и IRLS
