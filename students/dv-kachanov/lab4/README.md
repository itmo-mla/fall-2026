## Стандартизация данных: центрирование и масштабирование

Перед PCA выполняется стандартизация признаков по обучающей выборке. Сначала вычисляется среднее, затем — стандартное отклонение:

```text
mu_j    = (1/l) * sum_i F_raw[i, j],
sigma_j = sqrt((1/l) * sum_i (F_raw[i, j] - mu_j)^2).
```

Каждый признак центрируется и делится на своё стандартное отклонение:

```text
F  = (F_raw  - 1 mu^T) diag(sigma_1, ..., sigma_n)^{-1},
F' = (F'_raw - 1 mu^T) diag(sigma_1, ..., sigma_n)^{-1}.
```

Используется `ddof = 0`, как в `sklearn.preprocessing.StandardScaler`, поэтому после преобразования каждый столбец `F` имеет нулевое среднее и единичное стандартное отклонение. Параметры `mu` и `sigma` вычисляются только по обучению и затем применяются к контролю, поэтому утечки из контрольной выборки нет.

Ответ масштабировать не нужно: PCA работает только с матрицей признаков `F`, а для регрессии достаточно центрирования `y`:

```text
ybar = (1/l) * sum_i y_raw[i],
y = y_raw - ybar,
y' = y'_raw - ybar.
```

Полученные параметры стандартизации:

```text
mu = [ 1.01523468e-03  2.83420346e-04  2.32536802e-03  1.29485008e-03
       5.59402305e-04  4.79872588e-05 -5.94854447e-04  8.62619379e-04
       1.73777684e-03  3.25211819e-03];

sigma = [0.04638937 0.04758229 0.04713972 0.04782775 0.04806152 0.04823114
         0.047008   0.04826392 0.04797274 0.04740712];

ybar = 154.34441087613294.
```

Контроль стандартизации:

```text
макс. |среднее по столбцам F| после стандартизации = 3.508438923739921e-16;
макс. |std по столбцам F - 1| после стандартизации = 2.220446049250313e-15;
макс. |среднее y| после центрирования = 1.030394299591686e-14.
```

Датасет `diabetes` хранит признаки с нулевым средним и единичной нормой (`sum_i x_ij^2 = 1`), то есть его стандартные отклонения равны примерно `1 / sqrt(442) ~ 0.0476`, а не единице. Поэтому масштабирование здесь — содержательный шаг: оно приводит каждый признак к единичной выборочной дисперсии, а не оставляет данные почти без изменений.

## PCA через сингулярное разложение

Главные компоненты получаются из стандартизованной матрицы `F`:

```text
F = V D U^T,  S = F^T F,  G = F U,  Fhat = G U^T.
```

`numpy.linalg.svd` возвращает `(U_svd, s, Vh)` с `F = U_svd diag(s) Vh`, поэтому отображение на лекционные обозначения (см. `lecture_svd` в `source/pca.py`):

```text
V = U_svd,  D = diag(s),  U = Vh^T,  lambda_j = s_j^2.
```

Собственные значения `lambda` матрицы `S = F^T F` на стандартизованной обучающей выборке:

```text
[1297.12785094  487.40069315  422.74172942  331.1602322   218.71227468
  200.49082306  177.75491656  146.21360629   25.29351419    3.10435951].
```

Для сравнения спектр только с центрированием, без масштабирования:

```text
[2.96138238 1.10725387 0.95266702 0.74184609 0.48462408 0.44920643
 0.40432394 0.33043391 0.0582002  0.0071537 ].
```

Все `sigma_j` близки друг к другу (`0.04639 ... 0.04826`, различие около `4%`), поэтому масштабирование почти одинаково растягивает признаки: относительная структура спектра меняется слабо, а абсолютные значения увеличиваются примерно в `1 / 0.0476^2 ~ 441` раз. При этом сумма собственных значений становится равной

```text
tr S = ||F||^2 = l * n = 331 * 10 = 3310,
```

поскольку каждый стандартизованный столбец имеет сумму квадратов `l`. Это удобная проверка масштабирования: для данных только с центрированием было `||F||^2 = 7.497091630049979`.

Сингулярные числа `D` (диагональ, `sqrt(lambda_j)`):

```text
[36.01566119 22.07715319 20.56068407 18.19780844 14.78892405 14.15947821
 13.33247601 12.09188183  5.02926577  1.76191927].
```

Ключевой фрагмент (`source/pca.py`):

```python
F, mu, sigma = standardize(F_raw)
Fc, _, _ = standardize(Fc_raw, mu, sigma)

U_svd, s, Vh = np.linalg.svd(F, full_matrices=False)
V = U_svd
U = Vh.T
lam = s ** 2
G = F @ U[:, :m]
Fhat = G @ U[:, :m].T
```

## Эффективная размерность выборки

По лекции упорядочиваем `lambda_1 >= ... >= lambda_n >= 0` и выбираем наименьшее `m` с

```text
E_m = ||G U^T - F||^2 / ||F||^2
    = (lambda_{m+1} + ... + lambda_n)/(lambda_1 + ... + lambda_n) <= eps,
```

плюс критерий «крутого склона»: `E_{m-1} >> E_m`.

Относительные ошибки для стандартизованных данных:

```text
E_0 = 1.0;
E_1 = 0.6081184740362835;
E_2 = 0.46086750933784776;
E_3 = 0.3331509747689221;
E_4 = 0.23310256625065146;
E_5 = 0.16702635033465335;
E_6 = 0.10645510469865717;
E_7 = 0.052752712989622086;
E_8 = 0.008579418038288843;
E_9 = 0.0009378729644216241;
E_10 = 0.0.
```

При `eps = 0.05` наименьшее подходящее `m = 8`: `E_8 = 0.008579 <= 0.05`, а `E_7 = 0.052753` порога не проходит. Крутой склон подтверждается: `E_7 / E_8 = 6.15`, то есть `E_7 >> E_8`.

## Сравнение с эталонным PCA

Эталонный конвейер включает масштабирование, потому что `sklearn.decomposition.PCA` центрирует данные внутри себя, но не делит признаки на стандартные отклонения:

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler().fit(F_raw)
F_ref = scaler.transform(F_raw)
ref = PCA(n_components=n, svd_solver="full").fit(F_ref)
```

Параметры `scaler` совпадают с нашими `mu` и `sigma`, а собственные значения связаны с `ref.explained_variance_`:

```text
lambda_j = ref.explained_variance_[j] * (l - 1).
```

Собственные векторы SVD определены с точностью до знака, поэтому перед сравнением столбцы `U` согласуются с `ref.components_.T`:

```python
signs = np.sign(np.sum(U * U_ref, axis=0))
U_aligned = U * signs
G_ref = ref.transform(F_ref) * signs
```

Результаты сравнения:

## Ошибка восстановления

Абсолютная ошибка — квадрат нормы (сумма, без усреднения):

```text
||G U^T - F||^2 = 28.39787370673597,
хвост lambda_9 + lambda_10 = 28.39787370673608,
```

совпадение подтверждает теорему лекции (`||G U^T - F||^2 = lambda_{m+1} + ... + lambda_n`). Абсолютное значение больше, чем при одном центрировании, только потому, что после масштабирования вся матрица `F` и её спектр стали крупнее; относительная ошибка `E_8 = 0.008579` осталась малой.

## Регрессия

Данные стандартизованы, ответ центрирован, поэтому свободный член восстанавливается как `ybar`. Гребневая регрессия (параметр регуляризации `tau`; взято `tau = 1.0`):

```text
Q_tau(alpha) = ||F alpha - y||^2 + tau ||alpha||^2,
alpha*_tau = (F^T F + tau I)^{-1} F^T y.
```

```python
alpha_star = ridge_alpha_star(F, y, tau)
```

Результаты при `tau = 1.0`:

```text
alpha*_tau = [  2.27390102 -11.4397727   25.21469644  18.13079118 -34.26196577
               16.78489      1.19943013  11.6117361   29.58377377   1.36459301];
Q_tau(alpha*_tau) на обучении = 966473.0355962694;
Q(alpha*_tau, X^k) = ||F' alpha*_tau - y'||^2 на контроле = 315554.64432278357;
||alpha*_tau||^2 = 3569.493193457636.
```

Проверка формулы через SVD (`alpha*_tau = U (D^2 + tau I)^{-1} D V^T y`): отклонение от прямого решения `1.936228954946273e-13`.

Регрессия на сжатых признаках (слайд 24): `||G beta - y||^2 -> min`, `beta = U^T alpha`, `alpha = U beta`:

```text
beta* = [21.32611982 -13.3188021   15.31149899  25.00184606  -1.47893033
         13.9310418    5.96267047   1.11618685];
Q на обучении (сжатая, m = 8) = 972367.8415103415;
Q на контроле (сжатая, m = 8) = 315780.4450455336;
отклонение beta = U^T alpha: 2.1316282072803006e-14.
```

| Модель | Q на обучении | Q на контроле `||F' alpha - y'||^2` |
|---|---:|---:|
| Гребневая (`tau = 1.0`), все 10 признаков | 966473.035596 (`Q_tau`) | 315554.644323 |
| МНК на `m = 8` сжатых (`G beta`) | 972367.841510 | 315780.445046 |

## Анализ результатов

Эффективная размерность `m = 8`: наименьшее `m` с `E_m <= 0.05`, склон `E_7 / E_8 = 6.15`. Последние два собственных значения (`25.2935`, `3.1044`) малы по сравнению с первым (`1297.13`), но строго положительны.

Стандартизация изменила абсолютный масштаб задачи: `tr S` выросло с `7.4971` до `3310 = l * n`, а коэффициенты регрессии стали меньше, потому что признаки растянулись примерно в `21` раз (`1 / sigma ~ 21`). Относительный спектр изменился слабо: все `sigma_j` близки (разброс около `4%`), поэтому масштабирование действует почти как общий множитель. Доли объяснённой дисперсии при этом немного перераспределились: первая компонента объясняет `39.19%` вместо `39.50%` при одном центрировании.

Собственная реализация совпала с конвейером `StandardScaler + sklearn PCA` по средним, масштабам, спектру, сингулярным числам, главным направлениям, проекции, долям дисперсии и восстановлению с точностью `~1e-14` (см. `comparison.png`).

Сжатие `10 -> 8` сохраняет почти всю норму (`E_8 = 0.008579`). На контроле гребневая регрессия на всех 10 стандартизованных признаках даёт `Q = 315554.64`, а сжатая регрессия на `m = 8` — `315780.45`; различие около `0.07%`, при этом сжатая модель использует на два признака меньше. По сравнению с вариантом только с центрированием (`Q = 344707.41` для гребневой регрессии) стандартизация заметно улучшила качество на контроле на этом разбиении.
