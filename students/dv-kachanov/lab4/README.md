
## Предобработка

Перед применением `PCA` признаки стандартизируются:

```text
x'_j = (x_j - mean_j) / std_j.
```

`mean_j` и `std_j` считаются только по обучающей выборке. Затем те же значения применяются к тестовой выборке.

Стандартизация важна для `PCA`, потому что метод ищет направления максимальной дисперсии: без нее признаки с большими численными значениями доминировали бы в главных компонентах независимо от их информативности.

Центрирование для сингулярного разложения выполняется внутри реализации (`X_c = X - mean`).

## PCA через сингулярное разложение

В лекции показано, что главные компоненты получаются из сингулярного разложения центрированной матрицы:

```text
X_c = U Sigma V^T.
```

Строки матрицы `V^T` - собственные векторы выборочной ковариационной матрицы:

```text
S = (1 / (ell - 1)) X_c^T X_c = V Lambda V^T,
lambda_j = sigma_j^2 / (ell - 1).
```

Собственное значение `lambda_j` равно дисперсии проекции выборки на `j`-ю главную компоненту. Доля объясненной дисперсии:

```text
kappa_j = lambda_j / sum_{t=1}^{n} lambda_t.
```

В коде это реализовано в классе:

```python
MyPCA
```

Ключевой фрагмент:

```python
_, singular_values, Vt = np.linalg.svd(X_centered, full_matrices=False)
self.explained_variance_ = (singular_values ** 2) / (n_samples - 1)
self.explained_variance_ratio_ = self.explained_variance_ / total_variance
self.components_ = Vt[:self.n_components]
```

Проекция на главные компоненты и восстановление:

```python
def transform(self, X):
    return (X - self.mean_) @ self.components_.T

def inverse_transform(self, Z):
    return Z @ self.components_ + self.mean_
```

## Эффективная размерность выборки

Рассмотрены два критерия из лекции.

### Критерий Кайзера

Оставляются компоненты с собственными значениями выше среднего:

```text
lambda_j > (1 / n) sum_{t=1}^{n} lambda_t.
```

```python
def kaiser_dimension(eigenvalues):
    return int(np.sum(eigenvalues > eigenvalues.mean()))
```

Результат:

```text
k = 4.
```

### Порог накопленной дисперсии

Выбирается минимальное `k`, при котором накопленная доля дисперсии достигает заданного порога:

```text
sum_{j=1}^{k} kappa_j >= 0.95.
```

```python
def variance_threshold_dimension(ratios, threshold=0.95):
    return int(np.searchsorted(np.cumsum(ratios), threshold) + 1)
```

Результат:

```text
k = 8.
```

### Выбор размерности

В работе выбрана эффективная размерность:

```text
k* = 8.
```

Критерий Кайзера (`k = 4`) оставляет только направления с надсредней дисперсией, но отбрасывает компоненты 5-8 с суммарной долей около 21%, которые еще заметно уменьшают ошибку восстановления. Порог 0.95 сохраняет почти всю дисперсию данных при сжатии в 10 -> 8 признаков, поэтому для дальнейших экспериментов используется `k* = 8`.

## Анализ результатов

Собственные значения 9 и 10 близки к нулю, поэтому эффективная размерность выборки строго меньше 10. Критерий Кайзера дает 4, порог 0.95 дает 8; выбрано `k* = 8` как компромисс между сжатием и сохранением дисперсии.

Собственная реализация `PCA` через `np.linalg.svd` совпала с `sklearn.decomposition.PCA` с точностью до `2.2e-14` по проекциям.

Гребневая регрессия на сжатых признаках показала `MSE = 2843.503743` против `MSE = 2842.834634` на полных признаках, то есть снижение размерности не ухудшило качество.
