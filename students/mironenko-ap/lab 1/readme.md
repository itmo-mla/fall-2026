## 2. Отступ объекта

**Реализация:** `src/core.py::margin(X, y, w, b)`

```
M_i = y_i * (w^T x_i + b),   y_i ∈ {-1, +1}
```

Дополнительно `margin_stats` возвращает среднее, std, min, max, доли `m < 0` и `m < 1`.

**Визуализация:** `plot_margin_hist` (шаг 1 в `main.py`) — гистограмма отступов до обучения.

### Анализ (шаг 1 лога)

```

```

- `mean ≈ 0` — случайный классификатор не смещён;

- `доля m < 1 ≈ 0.908` — почти все объекты у границы.

## 3. Градиент функции потерь

**Реализация:** `src/core.py::loss_grad` (по всей выборке) и `loss_grad_sample` (по одному объекту).

Целевая функция:

```
L(w, b) = (1/2N) * Σ (w^T x_i + b - y_i)^2 + (λ/2) * ||w||^2
```

Градиенты:

```
∇_w L = (1/N) X^T r + λ w
∂L/∂b = (1/N) Σ r_i
r_i = z_i - y_i,  z_i = w^T x_i + b
```

**Проверка** (шаг 2): центральная конечная разность по 200 случайно выбранным объектам, `check_gradient`.

```
[grad-check] относительная ошибка = 1.10e-10
```

Ошибка на 5 порядков ниже порога `1e-6`, аналитический градиент корректен.

## 4. Рекуррентная оценка функционала качества (EMA)

**Реализация:** `src/core.py::EMA`

```
L̄_t = α * L̄_{t-1} + (1-α) * L_t
```

**Демонстрация** (шаг 3) на последовательности `[1.0, 0.8, 0.6, 0.5, 0.4]`:

```
α=0.9:   [1.0000, 0.9800, 0.9420, 0.8978, 0.8480]
α=0.99:  [1.0000, 0.9980, 0.9940, 0.9891, 0.9832]
α=0.999: [1.0000, 0.9998, 0.9994, 0.9989, 0.9983]
```

Чем ближе α к 1, тем инертнее кривая. В оптимизаторах EMA используется как сглаженная оценка **data-loss без L2**. Три значения α хранятся параллельно, строятся на графике `step3_ema_vs_loss.png`.

## 5. SGD с инерцией

**Реализация:** `src/optim.py::sgd_momentum`

```
v_w ← μ v_w - η g_w
w   ← w + v_w
```

Гиперпараметры: `lr = 5e-3`, `mu = 0.8`, `lr_decay = 0.05`, `epochs = 30`.

**Траектория** (momentum correlation random, L2 on):

```
ep  1/30 | train=6.6025 | val=4.3281 | acc=0.8571
ep 10/30 | train=0.3032 | val=0.2978 | acc=0.9524
ep 20/30 | train=0.1159 | val=0.1545 | acc=0.9405
ep 26/30 | early stop | val=0.1388 | acc=0.9405
  → test_acc=0.9762, ROC-AUC=0.9805
```

Большой «выброс» на первой эпохе — эффект инерции: момент разгоняет веса при первом крупном градиенте.

## 6. L2-регуляризация

Слагаемое `λ/2 * ||w||^2` встроено в `loss_grad`: даёт вклад `λ w` в градиент и `λ/2 * ||w||^2` в значение потери. Флаг `use_l2` управляет добавлением штрафа.

**Сравнение** `lam=1e-3` (on) и `lam=0` (off):

| Конфигурация | val_loss (on) | val_loss (off) | Δ |
|---|---|---|---|
| momentum correlation random | 0.1388 | 0.1381 | 0.0007 |
| momentum correlation margin | 1.3724 | 1.3713 | 0.0011 |
| steepest correlation | 0.1300 | 0.1300 | 0.0000 |

Эффект L2 **ниже точности измерения**. При `lam = 1e-3` и `||w||^2 ≈ 1.3` регуляризационный вклад `λ/2 * ||w||^2 ≈ 6.5·10⁻⁴`, тогда как data-часть ≈ 0.13 — L2 добавляет **0.5%** к целевой функции.

**Вывод:** при заданных гиперпараметрах L2 не влияет на качество.

## 7. Скорейший градиентный спуск

**Реализация:** `src/optim.py::steepest_descent` — полнобатчевый метод с точным шагом:

```
α_k = ||g_k||^2 / (g_k^T H g_k)
H = [[X^T X / N + λ I,   X^T 1 / N],
     [1^T X / N,         1       ]]
```

Гессиан предвычисляется один раз до цикла — это делает каждый шаг O(d²) вместо O(Nd).

**Траектория** (steepest correlation):

```
ep  1/30 | alpha=0.14481 | train=0.1723 | val=0.1482 | acc=0.9524
ep  5/30 | alpha=0.15888 | train=0.1374 | val=0.1321 | acc=0.9405
ep  8/30 | early stop | val=0.1300
  → test_acc=0.9881, F1=0.9836
```

За **8 эпох** val_loss = 0.1300 — на 10% лучше, чем momentum за 26 эпох.

## 8. Предъявление объектов по модулю отступа

**Реализация:** `src/optim.py::margin_order(X, y, w, b, reverse=False)` — сортировка индексов по `|M_i|`.

- `reverse=False` — **easy-first**: сначала с большим `|M_i|`;
- `reverse=True` — **hard-first**: сначала с малым `|M_i|`.

Порядок пересчитывается **каждую эпоху** (отступы зависят от текущих `w, b`).

**Результат easy-first** (momentum correlation):

| ordering | val_loss | test_acc | ROC-AUC | ‖w‖ |
|---|---|---|---|---|
| random | 0.1381 | 0.9762 | 0.9805 | 1.161 |
| margin | 1.3713 | 0.9762 | **0.9854** | **1.484** |

**Содержательный вывод:** easy-first катастрофически увеличивает `val_loss` (в 10 раз), но **не ухудшает** accuracy и слегка улучшает ROC-AUC. Механизм:

1. «Лёгкие» объекты идут первыми — SGD на них сильно раздувает `‖w‖`;
2. «Тяжёлые» приходят, когда модель уже далеко от оптимума;
3. Решение имеет большую норму → большие отступы → большие `|z−y|` → большой val_loss;
4. Но **порядок** скоров (ROC-AUC) от этого только выигрывает.

**val_loss ≠ качество классификации при squared loss.**

## 11. Случайная инициализация через мультистарт

**Реализация:** `src/init.py::multistart` — 5 независимых запусков с разными `w0 ~ N(0, 1/√d)`, выбор лучшего по val_loss.

**Результат** (фрагмент лога):

```
[momentum multistart | random]
  запуск 1: val_loss=0.1386
  запуск 2: val_loss=0.1410
  запуск 3: val_loss=0.1382
  запуск 4: val_loss=0.1384
  запуск 5: val_loss=0.1394
  лучший: 0.1382

[momentum multistart | margin]
  запуск 1: val_loss=1.4507
  запуск 2: val_loss=1.1152
  запуск 3: val_loss=1.1276
  запуск 4: val_loss=1.2725
  запуск 5: val_loss=1.2013
  лучший: 1.1152
```

**Наблюдения:**

1. С `ordering=random` разброс между стартами минимален (0.1382–0.1410) — задача выпуклая, все старты сходятся в одну точку, **multistart бесполезен**.
2. С `ordering=margin` разброс в 10 раз больше (1.11–1.45), потому что порядок зависит от текущих `w`. Multistart имеет смысл, но проигрывает correlation по val_loss.
3. Для `steepest multistart` — **парадокс**: результат (0.1416) хуже, чем у `steepest correlation` (0.1300). Причина — early stopping: разные старты останавливаются в разное время.
