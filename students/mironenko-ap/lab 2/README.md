# Отчёт о работе: KNN с ядром Парзена переменной ширины на датасете UCI Wine

## 1. Постановка задачи

**Цель работы:** реализовать алгоритм KNN с ядром Парзена переменной ширины (sample-point), подобрать параметр `k` методом leave-one-out (LOO), сравнить с эталонной реализацией `sklearn.neighbors.KNeighborsClassifier`, а также исследовать влияние отбора эталонов (CNN, ENN) на качество классификации.

**Датасет:** UCI Wine (178 объектов, 13 числовых признаков, 3 сбалансированных класса — `class_0`, `class_1`, `class_2`), загружается через `sklearn.datasets.load_wine`. Использование sklearn допускается только для загрузки данных и как эталон; вся арифметика KNN, LOO и отбора эталонов реализована на numpy.

## 2. Описание реализованных методов

### 2.1. ParzenKNN (наш алгоритм)

Файл `parzen_knn.py`. Реализован **KNN с гауссовым ядром Парзена и переменной шириной окна** (sample-point метод Парзена–Розенблатта):

- Каждому обучающему объекту $x_i$ сопоставлена своя ширина
  $$h_i = \rho_k(x_i) = \text{расстояние до его } k\text{-го ближайшего соседа (сам исключён)}.$$
- Оценка плотности класса $c$ в точке $x$:
  $$\hat p(x \mid c) = \frac{1}{N_c} \sum_{i:\, y_i = c} \frac{1}{h_i^{\,d}}\, K\!\left(\frac{\|x - x_i\|}{h_i}\right), \quad K(u) = e^{-u^2/2}.$$
- Предсказание: $\hat y = \arg\max_c \hat p(x \mid c)$.

**Численная устойчивость:** все вычисления ведутся в логарифмах — `log_w = -d·log(h_i) - 0.5·||x − x_i||²/h_i²`, а сумма по классу берётся через `logsumexp`. Это критично: при $d = 11$ и малых $h_i$ величина $1/h_i^d$ выходит за пределы представимости `float64`.

**Параметр `k`** в нашей модели — это не число соседей в голосовании, а параметр локальной ширины окна (номер порядковой статистики). При `k → ∞` окно расширяется, оценка становится всё более гладкой и смещённой; при `k = 1` — почти вырожденной, «приклеенной» к точкам.

### 2.2. Метрики

Файл `metrics.py`. На numpy реализованы `accuracy`, `confusion_matrix`, `precision/recall/F1` по классам и `macro_f1`.

### 2.3. LOO-подбор `k`

Файл `loo_search.py`. Эмпирический риск оценивается по схеме leave-one-out:

$$\hat R_{LOO}(k) = \frac{1}{n}\sum_{i=1}^{n} \mathbb{1}\{\hat y_{-i}(x_i; k) \neq y_i\},$$

где $\hat y_{-i}$ — предсказание по выборке без $i$-го объекта.

**Оптимизация:** полная матрица квадратов расстояний $D^2 \in \mathbb{R}^{n \times n}$ считается один раз; ширины $h_i$ также вычисляются один раз на полной выборке (стандартное приближение, при $n \gg k$ исключение одной точки практически не меняет $k$-е расстояние). Полный пересчёт $h$ на каждой свёртке дал бы сложность $O(n^3)$.

### 2.4. Отбор эталонов

Файл `prototype_selection.py`:

- **CNN (Condensed Nearest Neighbor, Hart, 1968)** — жадный алгоритм для 1-NN: стартуем с одного объекта каждого класса; добавляем точку, если текущее подмножество классифицирует её неверно; повторяем проходы до стабилизации.
- **ENN (Edited Nearest Neighbor, Wilson, 1972)** — удаляем точку $x_i$, если класс большинства её $k$ ближайших соседей не совпадает с $y_i$ (сглаживание шума).

## 3. Результаты

### 3.1. Подбор `k` методом LOO

Кривая эмпирического риска (`report/figures/loo_curve.png`, `loo_curve.csv`):

| k  | LOO-error |
|----|-----------|
| 1  | 0.1067    |
| 2  | **0.0955**|
| 3  | **0.0955**|
| 5  | 0.1461    |
| 7  | 0.1742    |
| 10 | 0.2303    |
| 15 | 0.3427    |
| 20 | 0.4607    |
| 25 | 0.5225    |
| 30 | 0.6067    |

**Оптимум:** $k^\star = 2$ (при ничьей с $k = 3$ берётся меньшее `k`). Минимум LOO-ошибки $\approx 0.0955$. Кривая имеет выраженный U-образный характер: при малых `k` окно слишком узкое (переобучение), при больших — слишком широкое (недообучение).

**Обоснование выбора гауссова ядра:** оно гладкое, бесконечно дифференцируемое, сепарабельное по координатам; нормировочная константа $(2\pi)^{-d/2}$ одинакова для всех классов и на argmax не влияет. Это классический выбор для оценки плотности (Парзен, 1962; Розенблатт, 1956).

**Обоснование переменной ширины (sample-point):** в задаче с тремя классами и 13 признаками плотность объектов распределена неравномерно; глобальная (fixed) ширина либо пересглаживает плотные области, либо недосглаживает разреженные. Локальная ширина $h_i = \rho_k(x_i)$ адаптируется к локальной геометрии данных.

### 3.2. Сравнение с эталонным sklearn KNN

Файл `compare_sklearn.py`, стратифицированный split 80/20 (`random_state = 42`), стандартизация по train. Результаты (`compare.csv`, macro-F1):

| k  | ParzenKNN (ours) | sklearn (uniform) | sklearn (distance) |
|----|------------------|-------------------|--------------------|
| 1  | 0.8286           | 0.9164            | 0.9164             |
| 2  | 0.8915           | 0.8878            | 0.9164             |
| 3  | **0.9230**       | 0.8876            | 0.8876             |
| 5  | 0.8424           | 0.9718            | **0.9718**         |
| 7  | 0.7755           | 0.9441            | 0.9441             |
| 10 | 0.8136           | 0.9452            | 0.9164             |
| 15 | 0.6925           | 0.9452            | 0.9452             |

**Наблюдения:**

1. Наилучший результат нашего алгоритма — **0.9230 (macro-F1) при k = 3**, что согласуется с LOO-оптимумом (k = 2–3).
2. sklearn-эталон достигает **максимума 0.9718 при k = 5** (и `uniform`, и `distance`). Здесь `k` - Это количество голосующих соседей, а не размер ядра
3. При больших `k` наш метод резко теряет качество — это ожидаемо, поскольку `k` здесь управляет шириной окна, а не голосованием: размытие плотностей классов при росте `k` приводит к систематической ошибке. У sklearn же рост `k` наоборот стабилизирует голосование.
4. Разрыв $\sim 5$ п.п. по macro-F1 объясняется:
   - `sklearn KNN` — дискретный голосующий алгоритм с адаптивной метрикой, устойчивый к выбросам при `weights='distance'`;
   - `ParzenKNN` — плотностная оценка; она даёт более гладкие, «вероятностные» границы, но хуже работает в режиме малой тестовой выборки (36 объектов) и при небольшом числе признаков, где локальная плотность сильно шумит.
5. Параметры алгоритма `ParzenKNN` (гауссово ядро, `k` из LOO, стандартизация по train) выбраны согласованно: LOO-оптимум k = 2–3 совпадает с тестовым оптимумом k = 3.

### 3.3. Отбор эталонов

Файл `prototype_selection.py`, split 80/20, `random_state = 42`, `k = 2` (выбран по LOO). Полный train = 142 объекта.

**CNN :**
- оставил **25 объектов (17.6 %)** от train;
- распределение по классам: см. `prototypes_cnn_idx.npy`.

**ENN :**
- сохранил **138 объектов (97.2 %)** — удалил лишь 4 шумовых точки;
- распределение по классам практически совпадает с исходным.

**Качество на тесте (`selection_compare.csv`):**

| Вариант | Accuracy | Macro-F1 | n_train |
|---------|----------|----------|---------|
| full    | 0.8889   | 0.8915   | 142     |
| cnn     | 0.6111   | 0.5721   | 25      |
| enn     | 0.8889   | 0.8915   | 138     |

**Наблюдения:**

1. **CNN резко ухудшает качество** (-28 п.п. accuracy): алгоритм жадный и ориентирован на 1-NN, поэтому оставляет только объекты вблизи границ классов. Для `ParzenKNN` с ядром и `k = 2` этого мало — плотности классов теряют «тело» распределения, оценки становятся неустойчивыми (в частности, для класса 2 остались считанные прототипы).
2. **ENN практически не меняет качество** (+0 п.п.), удаляя лишь 4 точки: датасет Wine чистый, и в нём почти нет объектов, чьи 3 ближайших соседа голосуют за другой класс. Это ожидаемый результат для хорошо разделимых данных.
3. **Вывод:** ENN-сжатие на Wine малоинформативно (сжимать нечего), а CNN в чистом виде неприменим к плотностным методам — его следует комбинировать с последующей реконструкцией плотности (например, через ядерную оценку по CNN-эталонам с подбором ширины).

### 3.4. Визуализация

**PCA-проекции** (`plots.py`, SVD-разложение центрированной матрицы, стандартизованные данные):

- `pca_scatter_with_enn_prototypes.png`: 138 из 142 прототипов подсвечены кружками. Прототипы равномерно покрывают все три класса — отсюда сохранение качества.
- `pca_scatter_with_cnn_prototypes.png`: 25 прототипов лежат в основном на границах кластеров; внутри плотных областей прототипов почти нет. Отсюда и просадка accuracy для `ParzenKNN`.

PCA на Wine показывает хорошую линейную разделимость: классы 0 и 1 частично перекрываются, класс 2 отделён почти линейно. Это объясняет, почему простые методы (sklearn KNN) дают высокое качество, а плотностный `ParzenKNN` на малой тестовой выборке чуть отстаёт.

## 4. Выводы

1. **Реализован** `ParzenKNN` — KNN с гауссовым ядром Парзена и переменной шириной окна (sample-point). Все вычисления в логарифмической шкале обеспечивают численную устойчивость при $d = 13$.
2. **Параметр `k`** подобран методом LOO: оптимум $k^\star = 2$ с LOO-error $\approx 0.0955$; на тесте лучшее качество при $k = 3$ (macro-F1 = 0.923). Кривая эмпирического риска имеет классический U-образный вид.
3. **Сравнение со sklearn** показывает близкие результаты при согласованных `k` (наши 0.923 при k = 3 vs sklearn 0.918 при k = 3), при этом sklearn-эталон на `weights='distance'` даёт максимум 0.9718 при k = 5. Разрыв объясняется плотностной (а не голосующей) природой нашего алгоритма.
4. **Отбор эталонов:** ENN на датасете Wine почти ничего не удаляет (138 из 142) и не меняет качество; CNN сильно сжимает выборку (25 из 142), но для плотностного `ParzenKNN` это приводит к деградации качества (macro-F1 падает с 0.89 до 0.57).
5. **Визуализация** PCA подтверждает результаты: ENN-прототипы равномерно покрывают классы, CNN-прототипы концентрируются на границах, что делает их малопригодными для восстановления плотностей.
