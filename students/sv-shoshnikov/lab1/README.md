Построить линейный классификатор, который по 30 измерениям опухоли предсказывает, злокачественная она или нет. Веса модели подбираются стохастическим градиентным спуском с инерцией, квадратичной функцией потерь и L2-регуляризацией. Сравниваются способы инициализации весов и способы выбора шага и объектов, результат сопоставляется с эталонной реализацией из sklearn.


ДАТАСЕТ

Breast Cancer Wisconsin (sklearn).
Объектов: 569 (455 train, 114 test, стратифицированное разбиение).
Признаков: 30.
Классов: 2 (злокачественная и доброкачественная опухоль), метки преобразованы в -1 и +1.

МОДЕЛЬ И ФОРМУЛЫ

Линейный классификатор:

    a(x) = sign( w·x + b )

Отступ объекта (больше нуля - верная классификация, модуль - уверенность):

    M = y · (w·x + b)

Эмпирический риск: квадратичная функция потерь и L2-регуляризация:

    Q(w, b) = (1/n) · сумма_i (1 - M_i)^2  +  λ · ||w||^2

Градиент риска:

    dQ/dw = (1/n) · сумма_i [ -2 (1 - M_i) · y_i · x_i ]  +  2λ·w
    dQ/db = (1/n) · сумма_i [ -2 (1 - M_i) · y_i ]

Стохастический градиентный спуск с инерцией (градиент g считается по батчу из 32 объектов):

    v = γ·v + (1 - γ)·h·g
    w = w - v

Рекуррентная оценка функционала качества (экспоненциальное скользящее среднее потерь по батчам, не требует прохода по всей выборке):

    Q = λ_b · ε_batch + (1 - λ_b) · Q,     λ_b = |batch| / n

Параметры: шаг h = 0.1, γ = 0.9, λ = 0.001, 100 эпох.


РЕАЛИЗОВАННЫЕ МЕТОДЫ (по пунктам задания)

П.2. Отступ. Вычисляется для каждого объекта, строятся гистограммы отступов для каждого метода.

П.3. Градиент. Выведен аналитически и проверен сравнением с численным градиентом (центральные разности), максимальное расхождение около 4e-11.

П.4. Рекуррентная оценка Q. Считается по ходу обучения и сравнивается с точным риском по всей выборке.

П.5-6. SGD с инерцией и L2-регуляризацией. Множитель (1 - γ) в формуле инерции нормирует накопленный шаг; без него шаг в 1/(1 - γ) раз превышает задуманный.

П.7. Скорейший градиентный спуск. Риск батча вдоль направления (u_w, u_b) является параболой по шагу h:

    Q(h) = mean( (1 - M_i + h·y_i·s_i)^2 ) + λ·||w - h·u_w||^2,     s_i = <u_w, x_i> + u_b

Её минимум считается аналитически на каждом батче:

    h* = ( <g_w, u_w> + g_b·u_b ) / ( 2 · ( mean(s^2) + λ·||u_w||^2 ) )

Важно, чтобы направление, по которому минимизируется риск, совпадало с направлением, по которому делается шаг. Формула h* верна для шага w = w - h*·u. Если применить её к скорости с инерцией v = γ·v + (1 - γ)·h·g, это условие нарушается: первый шаг составляет лишь (1 - γ) = 10% от вычисленного, а следующие идут в направлении накопленной скорости, а не антиградиента. Поэтому реализованы два отдельных режима (параметр step_rule):

    'steepest' - скорейший спуск без инерции. Направление u = g (антиградиент батча), шаг w = w - h*·g.
                 Параметр γ в этом режиме не используется. h* - точный минимум риска батча вдоль фактического шага.
    'steepest_momentum' - скорейший спуск с инерцией. Направление - скользящее среднее градиентов
                 u = γ·u_prev + (1 - γ)·g, шаг w = w - h*·u, h* - точный минимум риска батча вдоль u, то есть
                 вдоль фактического направления движения. Если <g, u> <= 0 (инерция направлена против
                 градиента), инерция сбрасывается: u = g.

Режим 'constant' (п.5) - обычный SGD с инерцией и фиксированным шагом, как раньше.

Ограничение шага (clip). Шаг h* считается по батчу из 32 объектов при 31 параметре, поэтому он точен только для этого батча и может быть слишком большим или слишком малым для всей выборки. Для защиты от выбросов h* ограничивается отрезком [0.001, 1.0] (параметры lr_min, lr_max; clip_step=False отключает ограничение). Верхняя граница страхует от больших шагов, нижняя - от остановки обучения, когда направление почти ортогонально градиенту. Если знаменатель формулы почти нулевой (меньше 1e-12), используется фиксированный шаг learning_rate. Реальное влияние ограничения измерено и приведено в разделе «Скорейший спуск: проверка и эксперимент».

Неполный батч. При n = 455 и размере батча 32 последний батч эпохи состоит из 7 объектов. Точный шаг по 7 объектам при 31 параметре очень шумный, и именно он определяет итоговые веса эпохи. Для скорейшего спуска неполный батч отбрасывается (параметр drop_last=True, в остальных режимах поведение прежнее). Эффект измерен в таблице 10 запусков ниже.

П.8. Предъявление объектов по модулю отступа. Вероятность попасть в батч выше у объектов с малым |M| (около границы):

    p_i ~ exp( -|M_i| / T )

П.9.1. Инициализация через корреляцию. Для каждого признака отдельно берётся коэффициент одномерной регрессии на метку:

    w_j = <y, f_j> / <f_j, f_j>

П.9.2. Мультистарт. 5 запусков со случайными малыми весами, лучший выбирается по риску на обучающей выборке (тест в выборе не участвует).

П.9.3. Случайное предъявление (обычное перемешивание) и предъявление по модулю отступа (п.8).

П.10-11. Метрики качества и сравнение с эталоном из sklearn.


МЕТРИКИ КАЧЕСТВА

Из матрицы ошибок (TP, FP, FN, TN) считаются:

    accuracy  = (TP + TN) / n
    precision = TP / (TP + FP)
    recall    = TP / (TP + FN)
    F1        = 2 · precision · recall / (precision + recall)

Выводы по скорейшему спуску:

- Со скорейшим спуском не нужен подбор шага. Главное преимущество видно в начале: при инициализации по корреляции (начальный риск около 90) скорейший спуск за первую эпоху снижает риск с 90 до 0.34, обычному SGD с h = 0.1 и γ = 0.9 нужно четыре эпохи, чтобы дойти до 0.28 (риск на эпохах 1-3: 1.92, 1.89, 1.22). SGD без инерции с h = 0.1 из такой точки расходится (шаг велик для начального градиента), поэтому для сравнения взят h = 0.01.
- По итоговому качеству скорейший спуск не превосходит SGD с подобранным шагом: средний риск после 100 эпох у него выше (0.229-0.250 против 0.216-0.229), точность на тесте в среднем одинакова (0.955-0.961), различия меньше одной ошибки на 114 объектов и не значимы. Причина: шаг минимизирует риск одного батча, а не всей выборки, и итоговые веса шумят вслед за последними батчами (стохастический градиент не затухает).
- Исключение неполного батча заметно снижает разброс риска скорейшего спуска (максимум по 10 запускам 0.377 -> 0.255).
- Инерция в скорейшем спуске результата не улучшает (риск 0.2445 против 0.2294 без инерции): при шаге, оптимальном для текущего батча, дополнительное усреднение направлений дало в этом эксперименте не выигрыш, а чуть больший риск (причину отдельно не исследовали).

ВЫВОДЫ

1. Реализован линейный классификатор с SGD, инерцией, L2-регуляризацией и квадратичной функцией потерь; аналитический градиент подтверждён численным.
2. Инициализация через корреляцию даёт детерминированный старт, но с завышенным начальным риском; обучение быстро его исправляет.
3. Мультистарт выбирает запуск по риску на обучении, поэтому тестовая выборка остаётся независимой.
4. Скорейший спуск требует согласования шага с направлением: шаг, оптимальный вдоль антиградиента, нельзя применять к скорости с инерцией. Реализованы два корректных режима (без инерции и с шагом, оптимальным вдоль фактического направления движения), формула проверена на сетке. Ограничение шага clip почти не срабатывает. Преимущество скорейшего спуска - быстрый выход из плохой начальной точки и отсутствие подбора шага, по итоговой точности он не лучше SGD с подобранным шагом.
5. Предъявление по модулю отступа работает без расходимости, риск сходится шумнее.
6. На одинаковой функции потерь собственная реализация совпадает с RidgeClassifier (94.74%); все методы отличаются на 1-5 объектов теста, что не значимо.
