# Лабораторная работа №3. SVM

В рамках лабораторной работы предстоит реализовать SVM и сравнить с эталонной реализацией алгоритма.

## Теоретическая часть

На лекции рассмотрели две постановки задачи SVM: аналитическая и геометрическая.
Показали, как геометрическая постановка приводит к задаче квадратичного программирования.
Рассмотрели решение двойственной задачи по лямбда.
Показали, как с помощью трюка с ядром можно строить нелинейные классификаторы.
Рассмотрели различные ядра и их свойства.
Рассмотрели различные способы регуляризации и их влияние на отбор признаков.


## Задание

1. выбрать датасет для бинарной классификации;
2. реализовать решение двойственной задачи по лямбда; для решения задачи использовать [scipy.optimize.minimize](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.minimize.html#scipy.optimize.minimize) или любую другую библиотеку;
3. провернуть трюк с ядром;
4. построить линейный классификатор;
5. визуализировать решение;
6. сравнить с эталонным решением;

## Вопросы для сдачи теории

На защите нужно не только воспроизвести определение, но и объяснить смысл формулы, интерпретировать результат на своём датасете и показать соответствующий фрагмент программы. **Основные вопросы** составляют ожидаемый минимум подготовки. **Дополнительные вопросы** предназначены для углублённого обсуждения; они не обязательны для каждой защиты.

### Основные вопросы

1. В чём идея **SVM**? Что означает максимизация зазора между классами и как ширина полосы связана с нормой \(w\)?
2. Что такое **отступ** в SVM? Какова роль кусочно-линейной функции потерь (hinge loss)?
3. Чем отличаются SVM с **жёстким** и **мягким** зазором? Для чего нужны переменные \(\xi_i\) и коэффициент \(C\)?
5. Какие ограничения должны выполняться для двойственных переменных \(\lambda_i\)? Каков смысл условий KKT?
6. Почему алгоритм называется **методом опорных векторов**? По какому признаку объект называется опорным?
7. Чем отличаются **периферийные**, **опорные граничные** и **опорные нарушители**? Как связаны их положение, отступ, \(\xi_i\) и \(\lambda_i\)?
8. Может ли опорный нарушитель быть классифицирован **правильно**? В каких случаях нарушитель действительно классифицирован неправильно?
9. Как восстановить решающее правило и свободный член \(w_0\) после решения двойственной задачи? Какие опорные векторы подходят для вычисления \(w_0\)?
10. В чём состоит **трюк с ядром**? В каком пространстве строится разделяющая гиперплоскость и нужно ли явно создавать дополнительные признаки?
11. Какие математические требования предъявляются к ядру SVM?
12. Какие вы знаете **конструктивные методы синтеза ядер**? Приведите примеры получения нового ядра из уже известных.
13. Чем отличаются линейное, полиномиальное и RBF-ядра? Как параметры ядра и \(C\) влияют на форму разделяющей поверхности?

### Дополнительные вопросы

15. Можно ли использовать в SVM произвольную функцию сходства, если она симметрична? Достаточна ли симметрия?
16. Обязано ли допустимое ядро SVM принимать **только неотрицательные значения**?
17. При использовании нелинейного ядра можно ли вычислять вектор весов SVM по формуле \(w=\sum_i\lambda_i y_i x_i\)? В каком пространстве находится разделяющая гиперплоскость? Нужно ли явно вычислять вектор \(w\)
