# Лабораторная работа №5. Логистическая регрессия

В рамках лабораторной работы предстоит реализовать логистическую регрессию и сравнить с эталонной реализацией алгоритма.

## Теоретическая часть
На лекции рассмотрели многомерную нелинейную регрессию. 
Свели задачу многомерной нелинейной регрессии к итерационному процессу IRLS. 
Рассмотрели решение задачи логистической регрессии с помощью метода Ньютона-Рафсона и IRLS. 
С другой стороны показали, как вероятностная постановка задачи классификации приводит к логистической регрессии. 

## Задание

1. выбрать датасет для логистической регрессии;
2. реализовать логистическую регрессию с помощью метода Ньютона-Рафсона и IRLS;
3. показать эквивалентность с эталонной реализацией;
4. подготовить отчет.

## Вопросы для сдачи теории

На защите нужно не только воспроизвести определение, но и объяснить смысл формулы, интерпретировать результат на своём датасете и показать соответствующий фрагмент программы. **Основные вопросы** составляют ожидаемый минимум подготовки. **Дополнительные вопросы** предназначены для углублённого обсуждения; они не обязательны для каждой защиты.

### Основные вопросы

1. Для какой задачи используется **логистическая регрессия**? Почему в её названии есть слово «регрессия», хотя итоговая задача часто состоит в классификации?
2. Как связаны **линейная комбинация признаков**, **сигмоида** и вероятность положительного класса? Что такое **логит** и функция связи?
3. Как из **модели Бернулли** и принципа **максимального правдоподобия** получается логарифмическая функция потерь (log-loss)?
4. Можно ли обучать классификатор методом наименьших квадратов? Почему для бернуллиевских ответов обычно используют другую функцию потерь?
5. Как работает **метод Ньютона–Рафсона**? Зачем ему нужны градиент и гессиан и чем он отличается от градиентного спуска?
6. Что означает **IRLS (Iteratively Reweighted Least Squares)**? Почему исходная задача сводится к последовательности задач взвешенного МНК?
7. Какие **веса объектов** возникают в IRLS для логистической регрессии? Что пересчитывается после очередной итерации?
8. Как связаны **метод Ньютона–Рафсона и IRLS** при решении логистической регрессии? Получают ли они принципиально разные направления обновления?
9. Что такое **обобщённая линейная модель (GLM)**? Какие три компонента нужны для её задания: распределение ответа, линейный предиктор и функция связи?
10. Какую функцию связи используют для нормального распределения, распределения Бернулли и распределения Пуассона?
11. Чем отличаются **бернуллиевская**, **биномиальная** и **пуассоновская** постановки задач? Приведите практический пример для каждой.

### Дополнительные вопросы

14. Почему логистическая регрессия с логитом является частным случаем GLM, а обычная линейная регрессия с гауссовским шумом тоже относится к GLM?
15. Чем **GLM** отличается от **GAM (обобщённой аддитивной модели)**, рассматриваемой на лекции?
16. Что произойдёт с коэффициентами нерегуляризованной логистической регрессии на идеально линейно разделимой выборке?
17. Зачем в регрессии могут понадобиться **квантильные** и **робастные** функции потерь вместо обычного квадрата ошибки?
